下载安装

原生桌面应用 · 开机自启 · 桌面与启动台快捷方式 · 托盘常驻

Windows 安装包（.exe） macOS 安装包（.dmg · Apple 芯片） 在线体验（网页版）

安装包由 GitHub Actions 自动构建，发布在仓库 Releases 页。Windows 安装后自动创建桌面与开始菜单快捷方式；macOS（Apple 芯片）拖入「应用程序」即出现在启动台，Intel Mac 可在本地按 README 构建命令 自行打包。开机自启与窗口置顶在应用内「设置」一键开启；关闭窗口不退出，三虎藏到系统托盘（左键找回、右键退出）。

它都能干什么

六个实用功能，全在点击弹出的工具栏里

截图 / 录屏

全屏或窗口录制，窗口模式下鼠标移到哪个窗口就出现高亮选框；截图一键存 PNG。

捕获

格式转换

图片互转 PNG / JPEG / WebP，文本转 PDF，视频转 GIF（前 6 秒）。拖进来就转。

文件

压缩 / 解压

ZIP 压缩可设密码，解压 ZIP / 7z / RAR（7z/RAR 需联网加载开源引擎）。

归档

定时提醒

到点主动提醒，支持每天重复；还能一键生成 Windows / macOS 定时关机脚本。

时间

待办清单

优先级、截止日期、筛选一应俱全，界面干净好看，数据存在浏览器本地。

效率

天气 + 下雨预警

城市 / 定位查询天气；未来 3 小时要下雨，三虎会主动表演 10 秒雨景提醒你带伞。
