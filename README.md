# 小白虎桌宠 (XiaoBaiHu Desktop Pet)

一个像素风白虎桌宠，单文件 HTML，无需安装，双击即用。支持：截图/录屏（全屏或窗口）、文件格式转换、ZIP 压缩（可设密码）/解压、定时提醒、待办清单、天气查询与下雨主动提示、鼠标交互。

## 使用

- **Windows**：双击 `启动桌宠-Windows.bat`（Chrome / Edge 无边框窗口模式）
- **macOS**：双击 `启动桌宠-macOS.command`（首次需右键 → 打开，或 `chmod +x`）
- 或直接用浏览器打开 `小白虎桌宠.html`

详细说明见 `使用说明.md`。

## 文件结构

```
小白虎桌宠.html         桌宠本体（单文件，精灵图已内嵌）
assets/                5 张像素精灵帧（160×160 透明 PNG）
启动桌宠-Windows.bat    Windows 启动脚本
启动桌宠-macOS.command  macOS 启动脚本
使用说明.md             使用说明
```

## 功能

| 功能 | 说明 |
|---|---|
| 截图 / 录屏 | 全屏或窗口录制（窗口模式下鼠标移到目标窗口出现高亮选框），截图存 PNG，录屏存 WebM |
| 格式转换 | 图片→PNG/JPEG/WebP；文本(txt/md/csv)→PDF；视频→GIF |
| 压缩 / 解压 | ZIP 压缩（可设密码）/解压；7z/RAR 解压（联网加载 7-Zip WASM） |
| 定时任务 | 定时提醒（可每天重复）；一键生成 Windows/macOS 定时关机脚本 |
| 待办清单 | 优先级、截止日期、筛选，数据存本地 |
| 天气 | 城市/定位查询；未来 3 小时将下雨自动提示并表演下雨动画 |
| 鼠标交互 | 跟随鼠标、点击反应、双击跑步、拖拽移动 |

## 技术说明

- 桌宠核心（精灵动画、待办、提醒、ZIP）离线可用；录屏、PDF/GIF、7z/RAR 解压、天气需联网。
- 开源组件（按需联网加载）：JSZip、pdf-lib、gifenc、7-Zip WASM；天气数据源 Open-Meteo。
- 浏览器限制：视频仅支持转 GIF/抽帧；浏览器无法直接关机/开机，采用生成系统脚本方案。
